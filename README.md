# THE LAST VISIT

## About the Project

THE LAST VISIT is an interactive mystery game developed using Python. 
Players explore investigation scenes, examine clues, and make decisions 
that influence the game's outcome.

## Features

- Interactive graphical user interface
- Mystery-based storyline
- Investigation scenes and clues
- Images and sound effects
- Different possible endings based on player decisions

## Technologies Used

- Python 3.11
- Tkinter for the graphical user interface
- Pygame for sound-related features
- Pillow for image handling

## Requirements

- Python 3.11
- Tkinter
- Pygame
- Pillow

## How to Run

1. Download or clone this repository.
2. Open the project folder in a terminal.
3. Install the required libraries if they are not already installed.
4. Run the following command:

```bash
python main.py
